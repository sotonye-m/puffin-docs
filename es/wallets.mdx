La API de Wallet-as-a-Service (WaaS) de Puffin te permite crear y operar
billeteras de stablecoins de forma programática — sin gestión de claves,
sin infraestructura específica por red, sin construir tu propia custodia.
Es la misma `X-API-Key` que ya usas para [intents de pago](/api/payment-intents).

<Note>
WaaS se lanza inicialmente con **USDC y USDT en Solana, Polygon, BSC y
Base** (Base es solo USDC — no existe un contrato canónico de Tether ahí).
Para cobrar cualquier red/token que Puffin soporte como pago puntual, usa
[intents de pago](/api/payment-intents) en su lugar.
</Note>

## Crear una billetera

```bash
curl -X POST https://api.puffinmoney.com/v1/gateway/api/wallets \
  -H "X-API-Key: mk_live_..." \
  -H "Content-Type: application/json" \
  -d '{ "chain": "BASE", "token": "USDC_BASE", "label": "EU settlement" }'
```

```json
// 201
{
  "wallet": {
    "id": "8f2a1c…",
    "chain": "BASE",
    "token": "USDC_BASE",
    "address": "0x9273...6544",
    "label": "EU settlement",
    "custodyModel": "joint_custody"
  }
}
```

La creación de billeteras está sujeta al límite de tu plan, igual que las
billeteras que ya podrías tener creadas desde el panel.

## Consultar un saldo

```bash
curl https://api.puffinmoney.com/v1/gateway/api/wallets/8f2a1c.../balance \
  -H "X-API-Key: mk_live_..."
```

```json
{ "wallet": { "id": "8f2a1c…", "chain": "BASE", "token": "USDC_BASE" }, "balance": { "available": "1250.00", "pending": "0" } }
```

## Enviar un retiro

```bash
curl -X POST https://api.puffinmoney.com/v1/gateway/api/wallets/8f2a1c.../withdrawals \
  -H "X-API-Key: mk_live_..." \
  -H "Idempotency-Key: wd_2026-07-22_001" \
  -d '{ "toAddress": "0xabc...", "amount": "500.00", "note": "Vendor payout" }'
```

El encabezado `Idempotency-Key` funciona igual que en los intents de pago —
repetir la misma key devuelve la respuesta original en lugar de enviar dos
veces.
