L'API Wallet-as-a-Service (WaaS) de Puffin vous permet de créer et
d'exploiter des portefeuilles de stablecoins de façon programmatique —
sans gestion de clés, sans infrastructure spécifique à chaque chaîne, sans
construire votre propre système de conservation. C'est la même
`X-API-Key` que celle que vous utilisez déjà pour les
[intentions de paiement](/api/payment-intents).

<Note>
WaaS est lancé initialement limité à **l'USDC et l'USDT sur Solana,
Polygon, BSC et Base** (Base ne prend en charge que l'USDC — il n'existe
pas de contrat Tether officiel sur cette chaîne). Pour collecter un
paiement ponctuel sur n'importe quelle chaîne/jeton pris en charge par
Puffin, utilisez plutôt les [intentions de paiement](/api/payment-intents).
</Note>

## Créer un portefeuille

```bash
curl -X POST https://api.puffinmoney.com/v1/gateway/api/wallets \
  -H "X-API-Key: mk_live_..." \
  -H "Content-Type: application/json" \
  -d '{ "chain": "BASE", "token": "USDC_BASE", "label": "EU settlement" }'
```

```json
// 201
{
  "wallet": {
    "id": "8f2a1c…",
    "chain": "BASE",
    "token": "USDC_BASE",
    "address": "0x9273...6544",
    "label": "EU settlement",
    "custodyModel": "joint_custody"
  }
}
```

La création de portefeuilles est soumise à la limite de votre forfait,
comme les portefeuilles que vous avez peut-être déjà créés depuis le
tableau de bord.

## Vérifier un solde

```bash
curl https://api.puffinmoney.com/v1/gateway/api/wallets/8f2a1c.../balance \
  -H "X-API-Key: mk_live_..."
```

```json
{ "wallet": { "id": "8f2a1c…", "chain": "BASE", "token": "USDC_BASE" }, "balance": { "available": "1250.00", "pending": "0" } }
```

## Envoyer un retrait

```bash
curl -X POST https://api.puffinmoney.com/v1/gateway/api/wallets/8f2a1c.../withdrawals \
  -H "X-API-Key: mk_live_..." \
  -H "Idempotency-Key: wd_2026-07-22_001" \
  -d '{ "toAddress": "0xabc...", "amount": "500.00", "note": "Vendor payout" }'
```

L'en-tête `Idempotency-Key` fonctionne exactement comme pour les
intentions de paiement — répéter la même clé renvoie la réponse
d'origine au lieu d'envoyer deux fois.
