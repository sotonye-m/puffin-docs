روابط الدفع هي عناوين URL قابلة لإعادة الاستخدام تُنشئها من لوحة التحكم.
كل زيارة تُنشئ نية دفع جديدة، لذا يمكن لرابط واحد استقبال عدد غير محدود من
المدفوعات.

## أنشئ رابطًا

1. لوحة التحكم → **روابط الدفع** → حدد عنوانًا، واختر العملة والشبكة.
2. حدد مبلغًا ثابتًا، أو اتركه فارغًا ليختار العميل (تبرعات، إكراميات،
   ادفع ما تشاء).
3. شارك `https://pay.puffinmoney.com/link/<slug>` — عبر الدردشة، أو فاتورة،
   أو توقيع بريدك الإلكتروني، أو رمز QR على إيصال، أينما شئت.

## الاستخدام البرمجي

أنشئ نية من رابط (نقطة نهاية عامة، دون مفتاح API):

```bash
curl -X POST https://api.puffinmoney.com/v1/gateway/public/links/<slug>/intent \
  -H "Content-Type: application/json" \
  -d '{ "amount": "10.00", "customerEmail": "buyer@example.com" }'
```

```json
{ "intentId": "9b1f…" }
```

ثم أرسل العميل إلى `/pay/<intentId>` أو افتحها عبر [SDK الـ iframe](/embed):

```js
PuffinPay.openLink({ slug: 'consulting-invoice-x7k2m9', amount: '150.00' });
```

<Note>
المبلغ مطلوب في الطلب فقط عندما لا يكون للرابط مبلغ ثابت.
</Note>
