---

पेमेंट लिंक ऐसे रीयूज़ेबल URL हैं जिन्हें आप डैशबोर्ड में बनाते हैं। हर विज़िट
पर एक नया पेमेंट इंटेंट बनता है, इसलिए एक ही लिंक से अनगिनत भुगतान लिए जा
सकते हैं।

## एक लिंक बनाएं

1. डैशबोर्ड → **Payment links** → एक टाइटल सेट करें, टोकन और चेन चुनें।
2. एक तय राशि सेट करें, या ग्राहक को खुद चुनने के लिए खाली छोड़ दें (डोनेशन,
   टिप, पे-व्हाट-यू-वांट)।
3. `https://pay.puffinmoney.com/link/<slug>` शेयर करें — चैट, इनवॉइस, ईमेल
   सिग्नेचर, रसीद पर QR, कहीं भी।

## प्रोग्रामेटिक इस्तेमाल

लिंक से एक इंटेंट बनाएं (पब्लिक एंडपॉइंट, बिना API key के):

```bash
curl -X POST https://api.puffinmoney.com/v1/gateway/public/links/<slug>/intent \
  -H "Content-Type: application/json" \
  -d '{ "amount": "10.00", "customerEmail": "buyer@example.com" }'
```

```json
{ "intentId": "9b1f…" }
```

फिर ग्राहक को `/pay/<intentId>` पर भेजें, या [iframe SDK](/embed) से खोलें:

```js
PuffinPay.openLink({ slug: 'consulting-invoice-x7k2m9', amount: '150.00' });
```

<Note>
राशि केवल तब रिक्वेस्ट में ज़रूरी है जब लिंक की कोई तय राशि न हो।
</Note>
