**Puffin Pay** 是 MacLeod Technologies 推出的稳定币支付网关。为您的客户提供支持
USDC、USDT、EURC 等更多资产的收银台——覆盖 Solana、Ethereum、Base、Polygon、
BSC、Arbitrum、Optimism 或 XDC——并以您希望的方式获得付款确认：签名 webhook、
实时仪表盘，以及客户可以保留的收据。

您可以自行决定集成的深度。零代码分享一个链接，用一行脚本在您的网站中嵌入结账
弹窗，或者用一次 API 调用从服务器端驱动整个流程——无论哪种方式，背后都是同一个
托管结账页面。

## 支付流程

1. 您创建一个**支付意图**（金额 + 代币 + 链）。
2. Puffin 为该笔支付生成一个**全新的收款地址**。
3. 客户完成支付；我们检测并在链上确认。
4. 支付意图变为 `CONFIRMED`，您的 webhook 被触发（HMAC 签名），仪表盘实时更新。

每个收款地址仅使用一次——没有金额匹配的启发式规则，不会出现支付混淆。

## 资金如何到账

已确认的支付会按照您账户配置的计划，结算到您自己掌控的钱包——参见
[结算](/settlement) 了解具体流程，以及如何指定到您自己的地址。

## 定价

费用按能力模块（支付、钱包、跨链桥接）根据您的套餐设置，并可随业务增长提供
定制费率——参见[团队与套餐](/teams-and-plans)了解定价结构，或查询
`GET /v1/gateway/merchants/me/fees` 获取您账户当前的具体数值。
