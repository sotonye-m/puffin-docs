## 团队角色（RBAC）

从仪表盘 → **Team** 邀请团队成员。成员使用邮箱登录——无需密码。

| 角色 | 权限 |
|---|---|
| `OWNER` | 全部权限，包括账单和团队管理 |
| `ADMIN` | 除账单外的全部权限 |
| `FINANCE` | 支付、提现、钱包、报表 |
| `DEVELOPER` | API 密钥与 webhooks |
| `SUPPORT` | 只读支付与客户信息 |
| `VIEWER` | 仅可查看 |

## 通知路由

每位成员都有按事件类型设置的邮件开关——`transactions`、`deposits`、
`payouts`、`subscription`、`security`、`reports`。您的财务负责人收到提现
邮件；工程师收到 webhook 失败通知；每个人都只收到与自己相关的邮件。

## 订阅套餐

| 套餐 | 适合场景 | 包含内容 |
|---|---|---|
| **Starter** | 试用 Puffin | 支付链接、托管结账 |
| **Growth** | 已上线的正式集成 | 包含 Starter 全部内容，另加 API、webhooks 和 iframe SDK |
| **Scale** | 高交易量商户 | 包含 Growth 全部内容，另加专属支持和定制化结算 |

套餐等级越高，钱包和团队席位上限越高，网关费率越低——请在
**仪表盘 → Billing** 查看当前定价与限额，或使用
`GET /v1/gateway/merchants/me/fees` 查询您账户的具体数值。高交易量商户可申请
定制费率——请联系支持团队洽谈。

## 商户钱包

在任意支持的链上创建收款钱包（仪表盘 → **Wallets**），最多不超过您套餐的
上限。网关支付始终使用全新的一次性地址，与您拥有的钱包数量无关。

## 按用量计费

定价按**能力模块**分别设置——Gateway（支付意图）、WaaS
（[钱包](/wallets)）和 Swap（[跨链桥接](/bridging)）——而非对所有功能统一
收取一个固定费率。每个能力模块都有两个独立的组成部分：

| 组成部分 | 涵盖内容 |
|---|---|
| **Platform** | Puffin 的利润部分 |
| **Gas** | 用于收回 Puffin 的 gas 站为您代付的网络 gas 费用 |

每个组成部分可以是百分比、固定费用，或两者兼有，并可设置可选的最低/最高
上限。您的实际费率是套餐默认费率，再叠加客户经理为您设置的任何定制调整。
查询 `GET /v1/gateway/merchants/me/fees`（仪表盘会话）获取每个能力模块的
精确当前数值，或在协商定制费率时咨询支持团队。
